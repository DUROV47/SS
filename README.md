# check.py — инвентаризация поверхности веб-сервисов

Утилита для **инвентаризации** веб-сервисов на IP-адресах из разрешённого
скоупа (например, в рамках программы ответственного раскрытия Standoff 365).

> Это **не** сканер уязвимостей и **не** инструмент эксплуатации. Программа
> только собирает информацию о поверхности: какие сервисы доступны, где есть
> формы входа, какие заголовки безопасности отсутствуют. Используются только
> безопасные методы (`GET`/`HEAD`), запросы ограничены по частоте.

## Что делает

Для каждой пары `IP:порт`:

1. Проверяет доступность порта (TCP-connect, таймаут 2 сек).
2. Если порт открыт — отправляет `GET /` по HTTP или HTTPS (таймаут 5 сек).
3. Фиксирует: код ответа, `Server`, `Location`, `Content-Type`, размер тела.
4. Определяет:
   - наличие формы входа (`<input type="password">`, `<form action="...login...">`);
   - наличие/отсутствие заголовков безопасности
     (`Strict-Transport-Security`, `Content-Security-Policy`,
     `X-Frame-Options`, `X-Content-Type-Options`);
   - наличие `X-Powered-By` (утечка технологии);
   - цепочку редиректов (`Location`).
5. Пишет отчёт в `report.txt` с тремя разделами:
   детальная инвентаризация, ресурсы с формами входа, ресурсы с
   отсутствующими заголовками безопасности.

## Ограничения (встроены)

- Не более **5 запросов в секунду** (rate limit).
- Только безопасные методы: **GET/HEAD**, ничего, что меняет данные.
- Таймаут **5 секунд** на HTTP-запрос, **2 секунды** на TCP-connect.

## Требования

- Python 3.7+
- `requests`:

```bash
pip install requests
```

## Запуск

```bash
python check.py scope.txt
```

Дополнительные опции:

```bash
python check.py scope.txt --ports 80,443,8080      # свой список портов
python check.py scope.txt --output myreport.txt    # другой файл отчёта
```

Порты по умолчанию: `80, 443, 8080, 8443, 8000, 3000, 5000, 9000`.

## Формат scope.txt

По одному IP в строке. Пустые строки и строки с `#` игнорируются.

```
192.0.2.10
198.51.100.25
```

## Важно

Используйте утилиту только против систем, явно входящих в разрешённый скоуп
программы, участником которой вы являетесь.
